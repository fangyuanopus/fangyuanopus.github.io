# Su Junpeng | Personal Space

这是我的个人网站和个人博客主页，用来展示公开项目、学习记录、工具兴趣和最近在探索的方向。

线上地址：[https://fangyuanopus.github.io/](https://fangyuanopus.github.io/)

## About

我叫苏俊朋，也常用 `fangyuanopus` 这个 ID。

我平时喜欢使用 Claude Code、Codex 等 AI 开发工具辅助学习、办公、写代码和整理想法，也会做一些小型 Web 应用、自动化流程和 PPT/文档工具。未来希望进一步研究并构建更适合自己学习和工作场景的开发 agent。

## What This Site Contains

- 个人介绍和联系方式
- 公开项目展示
- AI 工具、开发 agent、接口机制和自动化相关学习记录
- 常用工具栈和兴趣方向

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Three.js
- GitHub Pages

## Development

```bash
pnpm install
pnpm dev
```

Build static files:

```bash
pnpm build
```

The static export is generated in `out/`.

## Deployment

This site is deployed to GitHub Pages through GitHub Actions.
